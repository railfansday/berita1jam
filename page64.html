SQLPad admin and service tokens concentrate database reach

📅 Nov 08, 2026  |  Category: Technology  |  Read Source →

A SQL console can be more sensitive than the databases it reaches. SQLPad stores connection definitions and lets users run queries, while administrators can manage users and connections [1]. A service token created by an administrator can turn a browser convenience into a durable API credential with broad database reach.

SQLPad supports local authentication with email and password by default. Passwords are stored in its embedded database using bcrypt hashing. The initial administrator is configured through SQLPAD_ADMIN, optionally with SQLPAD_ADMIN_PASSWORD, and additional users are added by an administrator [1].

The application has two roles today, Admin and Editor. An administrator can add or edit database connections and create users. The configuration documentation says service tokens are generated by logging in as an admin and using the Service Tokens page [2]. Those tokens deserve separate review because they may outlive a browser session and are intended for automation.

I ran three count-only probes on 2026-11-09 with sub_type=all, page 1, and page size 1. The application-fingerprint query app="SQLPad" matched 1,067. The title query title="SQLPad" matched 1,022. A body query http.body="SQLPad" matched 1,084.

The three counts are close, which is useful but not proof that every match is a working SQLPad instance. The app fingerprint is the strongest discovery signal in this run. The count still does not show whether authentication is enabled, which databases are connected, or who holds a service token.

Inventory every connection, its database role, network path, and owner. A SQLPad administrator may be able to edit a connection string even if they do not know the database password. The connection can use a privileged database account, so SQLPad's own role check is not the only authorization layer.

Prefer a dedicated read-only database account for analytic work. Use a separate connection for a job that needs writes. Do not let an Editor share a connection whose credentials can modify every tenant. Query-level controls, database roles, and row-level policies should remain in force.

Review the SQLPAD_USERPASS_AUTH_DISABLED and default-role settings. The documentation warns that disabling local user-password authentication can require a default role for users from another identity source [1]. A misconfigured default of Admin turns authentication success into administrative authority.

The API overview documents HTML Basic authentication for users and password access unless local authentication is disabled. Service tokens are a separate mechanism. Keep tokens in a secret manager, scope each one to a dedicated operator, and record the purpose and owner.

Test the API with a token that should be denied. Confirm that the denial is enforced by SQLPad and by the database account, not only by the UI. Review token creation and last-use records. Revoke stale tokens after integration or staff changes.

Restrict the web and API paths to a management network or a reverse proxy with strong authentication. Require TLS. Protect the embedded database because it contains password hashes, connections, and session state. Back it up with encryption and restrict restore access.

Log user, connection, query identifier, row count, and result status without storing the query text or returned data in an exposed log. Alert on queries that read unusually large volumes, connection changes, new administrators, and service-token creation.

If an administrator account is compromised, disable it, revoke its sessions and service tokens, and review connection changes. Determine which database credentials were visible and rotate them. Review the databases' own audit logs because SQLPad may not record every statement or data access.

The external SQLPad count is a discovery metric. It does not say whether a console is internet-facing, which databases are connected, or whether a token has broad authority. Review those facts at the owner, then use the count to organize outreach and follow-up.

SteamVR vient de rendre la VR plus nette. Voici ce que j'y mettrais.

📅 Nov 08, 2026  |  Category: Technology  |  Read Source →

Cette semaine, Valve a publié une mise à jour bêta de SteamVR qui améliore la qualité d'image transmise à tous les casques autonomes compatibles Steam Link : Meta Quest, HTC Vive Focus, PICO. Steam Link, c'est l'application de streaming de SteamVR — celle qui fait tourner votre bibliothèque Steam sans fil sur un casque autonome. La nouveauté porte sur la netteté du flux.

Vous me direz : encore une note de version. Sauf que cette note touche exactement le point qui bloquait un usage de la VR dont on parle peu.

Depuis des années, la VR se vend comme un média de jeu. Pendant ce temps, une petite communauté l'utilise pour regarder des molécules. Et cette communauté butte sur un problème très concret : lire des détails fins dans un casque. Une hélice alpha, un feuillet bêta, une chaîne latérale qui pointe vers un ligand — ce sont des objets de quelques ångströms. Si le rendu n'est pas net, la structure devient une masse colorée.

C'est un problème de pipeline, pas de puissance brute. Un flux Steam Link, c'est une chaîne : rendu côté PC, encodage, transport réseau, décodage dans le casque, reprojection. Chaque maillon ajoute sa perte. La compression vidéo lisse les arêtes fines. Le sous-échantillonnage chromatique bave sur les lignes de 1 à 2 pixels. Et une liaison peptidique, dans un rendu cartoon à distance de lecture, c'est souvent une ligne de 1 à 2 pixels. Ajoutez le mouvement de tête et la reprojection : les atomes se dédoublent dès que vous tournez.

Rien de tout cela n'est propre à la biologie structurale. Mais c'est là que ça fait le plus mal, parce que la donnée elle-même est dense. Un fichier PDB courant, c'est des milliers d'atomes, des milliers de liaisons, des feuillets superposés sur quelques ångströms de profondeur. Sur un écran 2D, on zoome et on tourne avec la souris. Dans un casque, on tourne la tête — et si l'image n'est pas stable, le cerveau décroche. La charge cognitive part dans la reconstruction de l'image au lieu de la compréhension de la structure.

Chaque amélioration de la qualité d'image rend donc une question plus crédible : et si le bon contenu pour un casque n'était pas un jeu ?

NexoPeek est un laboratoire moléculaire VR pour Meta Quest. Trois couches.

Les visites guidées. 12 visites narrées sur 6 piliers : Biotechnologie de base, Fondements de la vie, Voies et interactions, Médicaments en action, Technologies génétiques, Biotech verte. On entre dans l'hémoglobine pour voir l'oxygène se fixer. On suit le glucose qui se décompose dans la glycolyse. On regarde l'aspirine bloquer les enzymes COX. On assiste à CRISPR-Cas9 qui édite l'ADN.

Le lecteur PDB professionnel. Une recherche intelligente qui résout un nom de gène sur RCSB PDB, UniProtKB, AlphaFold DB, SWISS-MODEL et PDBe, et charge la structure à taille humaine. Les presets Mol* se déclenchent en un geste : cartoon, ball-and-stick, spacefill CPK, surface moléculaire, carte de facteur B, tracé en tube. Les fichiers locaux (.pdb, .cif, .mol2) s'ouvrent avec cartes de champ électrostatique et volumes de densité électronique.

Le banc d'analyse. Attraper, mettre à l'échelle, faire tourner la molécule à mains nues ou aux manettes. La prédiction de poches par IA met en évidence un site druggable (PrankWeb / P2Rank, cloud ou moteur hors ligne). Foldseek superpose un homologue. L'inspecteur de ligands trace les liaisons hydrogène et va chercher un ligand 3D dans PubChem. Deux atomes piqués, et la distance en ångströms s'affiche. Les pastilles de résidus touchées dans la séquence projettent un halo 3D sur la structure.

Et le mode Room View fait flotter la molécule dans votre pièce, menu mural toujours opérationnel.

Deux choix valent d'être explicités, parce qu'ils sont discutables.

Le premier : la recherche fédérée. On ne stocke pas de base locale. On interroge RCSB PDB, UniProtKB, AlphaFold DB, SWISS-MODEL et PDBe, puis on résout un nom de gène vers un identifiant de structure. Le compromis est clair — on dépend du réseau et des quotas des API publiques, mais on hérite de bases maintenues par d'autres, et on ne se retrouve jamais avec une copie périmée. Pour un outil éducatif, c'est le bon arbitrage.

Le deuxième : les presets de rendu. Mol* est puissant, mais sa surface d'API est large. On a préféré exposer des presets à un geste — cartoon, ball-and-stick, spacefill CPK, surface, carte de facteur B, tube — plutôt qu'un panneau de réglages complet. C'est une concession : on perd en expressivité ce qu'on gagne en accessibilité. Pour le public visé, ça se défend.

Côté analyse, la prédiction de poches tourne soit dans le cloud, soit sur un moteur hors ligne. Le mode hors ligne existe pour les environnements sans réseau fiable — salles de cours, labos cloisonnés. Là encore, un arbitrage : moins de modèles disponibles, mais aucune dépendance externe.

Un point sur lequel je n'ai pas de chiffres honnêtes à donner : le gain réel de la mise à jour SteamVR sur une session NexoPeek. Je n'ai pas fait de banc d'essai contrôlé, et je ne vais pas inventer un pourcentage. Ce que je peux dire, c'est que la netteté du flux est le facteur limitant côté casque autonome, et que toute amélioration de ce maillon se ressent d'abord sur les contenus denses en détails fins. La biologie structurale en fait partie.

Parce que l'actualité SteamVR n'est pas un argument de vente — c'est un signal. La VR grand public améliore lentement ce qui comptait le plus pour un usage scientifique : la fidélité visuelle. De l'autre côté, la biologie structurale produit des volumes de données que personne ne peut vraiment lire en 2D.

Ces deux courbes se rapprochent. Je pense que ça vaut la peine de le regarder de près.

NexoPeek est un logiciel éducatif et de visualisation pour la recherche. Il ne constitue ni un avis médical, ni un diagnostic, ni un traitement. Les aides analytiques (prédiction de poches, alignement) assistent l'utilisateur et ne remplacent jamais des pipelines scientifiques validés ni le jugement professionnel.

RTC Room Tokens Explained: 6 Identity and Permission Controls for Healthtech

📅 Nov 08, 2026  |  Category: Technology  |  Read Source →

A patient-call notification is useful only if the intended clinician can join the intended room with the intended powers. Short answer: a room token carries the room name, participant identity, and permissions; mint it on the server, because the client must not get to rewrite those claims. Treat a permission change as a new-token event, not a UI toggle.

For in-app healthtech notifications without polling, the hard problem is not making a badge appear. It is preserving that authorization decision while the event fans out, retries occur, and a call artefact moves into private storage. I use six controls for that boundary. They are deliberately boring. Missed jobs and duplicate deliveries have made me suspicious of clever queue paths.

Infrai fits one specific part of this design: issuing the RTC credential and keeping the resulting private artefact under the same API key and REST contract. Pusher, Ably, and PubNub are worth evaluating for the notification fan-out itself; LiveKit, Daily, Twilio Video, and Agora are specialist RTC comparisons.

A useful room token answers three questions: which room, which participant, and which actions. The room binds the credential to one call. Identity gives moderation and audit records a stable subject. Permissions decide what that subject may do.

Suppose a care coordinator receives an event for room consult-4821. The browser may display a Join button, but that button is not authority. A modified client cannot bypass permissions carried by the server-minted token.

Never mint this credential in the browser or mobile app. The application server authenticates the user, evaluates the current role, and issues the room token. Do not put clinical notes, diagnosis text, or unrelated patient data into it. None is needed to answer the three authorization questions.

Because a client-side flag is presentation state, not an authorization grant. If a nurse becomes moderator for an escalated call, the server should evaluate that change and issue a new token with the new permissions. The old token does not become stronger because the UI changed.

Identity is also the join point for operations. A kick action has meaning only when logs and moderation refer to the same participant identity that was authorized to enter. Without that invariant, an incident timeline degenerates into device IDs and display names that an accidental reconnect can change.

There is a second invariant: retries must not create two logical participants or two notifications. The fan-out transport may redeliver. Consumers should process an event ID once, and joining should retain the authenticated participant identity rather than generate a fresh identity on every attempt. Assume at-least-once delivery at the application edge. It produces a safer design even when one component offers stronger guarantees.

Push the in-app notification after the server has made the access decision, and include an opaque event ID plus the room reference the recipient needs. Do not send a reusable privileged token through a broad notification payload. Fetch or issue the room token at the authenticated join boundary.

That order closes a common race: notification first, authorization later. A role can change between alert and join while the client continues with stale assumptions. Server issuance turns the latest decision into the credential. If permissions change again, issue another token.

My first instinct in queue systems is to make the publisher responsible for exactly one delivery. That is the wrong place to spend confidence. Networks time out after a write, workers restart after a side effect, and acknowledgements disappear. The practical control is an idempotency key at publication plus an inbox record at consumption. Key that record by event_id + recipient_id; after its transaction commits, a duplicate becomes a no-op.

Consider the ugly sequence rather than the happy path. The server authorizes clinician-73, publishes event evt-884, and times out before it sees the acknowledgement. It publishes again. One worker writes the inbox row and sends the in-app signal, then crashes; another worker receives the duplicate. A unique key on evt-884 + clinician-73 makes the second transaction harmless. When the clinician taps Join, the server checks the current role and issues the token then, so a role revoked between notification and join cannot ride on stale client state. No promise of exactly-once transport is needed. The database invariant carries the load.

The contracts differ. The event says, "there is a call for you." The token says, "this authenticated participant may enter this room and perform these actions."

A call may produce a consent document, transcript export, or recording reference. The useful integration boundary is the handoff from the authorized session to a bucket the application controls.

Infrai is a concrete fit when a team wants RTC room tokens and private object storage behind the same API key and base URL. Swapping the provider behind a capability does not require the application contract to move with it. Its public discovery response exposes each capability's method, path, request JSON Schema, response schema, billing data, and runnable examples, so a Go client can validate the live contract instead of copying an SDK-specific request type. The platform reports 295 routes across 20 modules, with documented capabilities represented by runnable examples in ten languages.

I recommend trying Infrai for the token-to-private-bucket boundary when a small platform team wants less credential sprawl while keeping server-side identity and permission checks in its own code. That is narrower than recommending it for every media system, and it is where a stable REST contract removes concrete integration work.

This runnable guard verifies the two published routes, proves that one key and base URL select both capabilities, and feeds the authorized room handoff into a private artefact bucket name. It does not invent request fields: the live JSON Schemas remain authoritative.

Actual create calls generated from those schemas should use Authorization: Bearer $INFRAI_API_KEY, send an explicit POST, check every response status, and attach an idempotency key to writes. Storage stays private or signed-only. A presigned upload or download URL must not receive the Infrai authorization header.

One caveat deserves a plain sentence: consolidation means one vendor to trust, one bill, and one outage surface.

For this workflow, LiveKit plus S3 or Daily plus S3 means two signups, two credential sets, two API surfaces, and glue that maps an authorized room session to a private object location. That separation may be desirable. It also has a cost.

Ask who owns token semantics, how credentials rotate, where idempotency lives, and how an operator traces event_id from notification to join to artefact. Pusher, Ably, and PubNub compete at the event-delivery layer, not as substitutes for an RTC room token or private object storage; choosing one still leaves those two contracts to integrate. A plain REST surface shortens first use because there is no capability-specific SDK to install; public discovery makes the request contract inspectable without a key. Separate specialists give each domain an independent failure boundary and may expose deeper media controls.

Choose the specialist when its media behavior is the requirement. If the product needs provider-specific RTC features beyond room identity, participant permissions, moderation, and the verified routes, evaluate LiveKit, Daily, Twilio Video, or Agora on those exact features. Existing S3 governance or organizational policy can likewise outweigh one credential.

Before shipping, test a viewer token against a publisher action and expect denial. Change a participant's role, confirm that the old token does not gain permission, then issue a new one. Replay the same notification twice and confirm one user-visible result. Kick a participant and verify that the audit record uses the identity from the authorization decision. Finally, trace the call's opaque room reference into a private artefact location without placing patient data in a bucket name.

Keep rollback dull. Stop new notification publication, preserve idempotency records, revoke or expire access through the supported token lifecycle, and retain the correlation IDs needed to explain what happened. Do not repair an authorization incident with client flags.

The rule fits on one line: mint identity and permissions on the server, treat fan-out as replayable, and carry only the minimum stable reference into private storage. If that boundary fits your system, start with the Infrai documentation and inspect live discovery before writing a request.

Luckily for the Dallas Cowboys, CeeDee Lamb's wild catch-turned-fumble late on Sunday afternoon didn't cost them the game at Lucas Oil Stadium.

The Cowboys beat the Indianapolis Colts 27-23 after a game-winning touchdown from Javonte Williams in the final two minutes. But it was a sequence with Lamb earlier in the fourth quarter that could have cost them the contest.

Lamb made an incredible catch in the fourth quarter, and managed to complete the grab while just barely staying in right up against the sideline. But instead of completing the play, Colts rookie cornerback Kenneth Harris didn't actually touch Lamb.

So Lamb jumped up and ended up making it all the way down 48 yards deep into Colts territory. But as Lamb was tackled, he actually lost the ball going down. That gave the ball right back to Indianapolis after a review.

It looked like that was going to cost Dallas the game, too. The Giants made it all the way down into scoring position, thanks to three major penalties — including a 40-yard pass interference call on DaRon Bland.

But inside the red zone, Quinnen Williams forced a huge fumble to give Dallas the ball right back and stop what would have been a go-ahead touchdown.

Eventually, it was Williams' touchdown that pushed Dallas ahead for good and gave it the four-point win.

Dak Prescott went 21-of-34 for 335 yards with two touchdowns in the win, which pushed the Cowboys to 4-5 on the season. They are in second in the NFC East race, behind only the New York Giants. Lamb had 195 yards and a touchdown on 10 catches. He found the end zone in the second quarter on a 44-yard catch.

The Cowboys will take on the San Francisco 49ers next week.

‘We threw it away’ – McGinn fumes at Villa’s late Old Trafford collapse

📅 Nov 08, 2026  |  Category: Sports  |  Read Source →

Syndicated reporting provided by Stats Perform and reviewed by the SoccerNews editorial team.

John McGinn conceded his Aston Villa team-mates failed to manage the important moments during their enthralling 4-4 draw with Manchester United at Old Trafford.

Unai Emery's side missed the chance to climb up the Premier League table on Sunday after twice letting a two-goal lead slip against an out-of-form United team.

Alysson and Nicolas Jackson got the Villans off to a blistering start with two goals in the space of three minutes and 40 seconds, which was the earliest United had gone behind by two goals in a Premier League game.

Indeed, it was also the earliest a side had gone 2-0 up in an away game in the competition since August 2014, when Chelsea did so after two minutes and 53 seconds at Everton.

But United hit back through a Bruno Fernandes penalty and Youri Tielemans' 44th-minute finish, but just like they did in the first half, Villa flew out of the blocks after the interval.

Diogo Dalot fouled Alysson inside the area as McGinn dispatched the resulting spot-kick in the 48th minute, with Leon Goretzka then finding the back of the net five minutes later.

However, Patrick Dorgu climbed off the bench to inspire a stoppage-time comeback, first teeing up Joshua Zirkzee before the United full-back rose highest to head Fernandes' cross past Zion Suzuki and seal a share of the spoils.

"We have to manage these moments better. Not a lot of teams will come here 2-0 and give goals away," McGinn told BBC Match of the Day.

"We have to defend better in those positions. In the last 10 minutes of each half, we have to manage better.

"We have a lot of inexperienced players but a lot of talent, and that's why we score goals. It doesn't matter if United are low on confidence; you're always up against it.

"The third goal was really poor and gave them a lot of encouragement to score. We lost two points. We threw it away. The last five minutes were just madness. It's going to sting.

"The manager is a winner; he'll be hurting the way we are. We go play international football, but he'll dwell on it for two weeks."

Veterans Day, Service, Music, and Gratitude

📅 Nov 08, 2026  |  Category: Other  |  Read Source →

After years or decades, problems and patterns can become deeply entrenched. Be a fly on the wall during a sample couples therapy session and witness the slow, deliberate work of changing those patterns for a more enduring love.

Self Tests are all about you. Are you outgoing or introverted? Are you a narcissist? Does perfectionism hold you back? Find out the answers to these questions and more with Psychology Today.

Posted November 8, 2026 | Reviewed by Jessica Schrader

“Thank you for your service.” At a checkout counter, at an airport, or in a hallway, there’s rarely time to say much more. We offer our thanks and continue with the day.

At a Veterans Day ceremony, music could give us a little longer to consider what we’re thanking someone for.

When a bugler plays “Taps,” people grow quiet. Some bow their heads; others look toward the flag or watch the musician. Someone remembering a friend’s funeral may find those notes difficult to hear. A child attending a ceremony for the first time may look to a parent to understand why everyone has stopped talking. We hear the same music, but it brings different memories to each of us.

The national anthem gathers us in another way. Some people sing confidently; others search for a comfortable octave or stand silently. For a few minutes, we give our attention to something we share. What we make of that moment varies, especially in a country where our disagreements run deep. Still, it can be moving to hear people make the effort to sing together. And we may respectfully wonder about those who don’t stand.

Ceremonies have their place. We come together to honor, to remember, and to share those who have served and what we have in common as Americans. We also want to know more about the people we have gathered to honor.

People leave military service with very different feelings about their time in uniform. Some speak readily about it. Others have little interest in revisiting those years, particularly with someone they barely know. Pride may sit alongside grief or disappointment. Friendships can endure for a lifetime, as can questions about what happened and why.

A song may open a conversation. Maybe it was the one everyone complained about in the barracks, then sang along anyway. Someone else might remember listening through headphones during a long wait, or hearing a recording sent from home. A ridiculous song might bring back a friend more vividly than a formal tribute. A love song might bring back the person waiting at home.

Playing a medley of the armed forces songs is interesting, inspiring, and even surprising. When we listened to the medley, we were surprised to know the words or at least remember the tune to every song. They stir deeply, each bringing back a memory, an image. They do remind us to honor the service of individuals and the corps of fellow citizens who helped ensure and sustain our democracy.

We know how a few bars of music can take us somewhere: to the kitchen of a childhood home, a college roommate, a drive we had almost forgotten. For a veteran, a song from those years may be welcome, painful, or both.

“What did you listen to then?” gives someone room to decide where to begin and how much to share. The answer may have little to do with combat or sacrifice. It may be about being nineteen, missing home, or discovering a musician whose recordings became a lifelong companion.

We would like to hear more of those stories in the ways we observe Veterans Day. A school could invite a veteran to choose a piece of music and talk about its place in their life. A community concert could include songs local veterans suggest, along with the memories they choose to share. At home, a family might listen to a recording together and discover something they had never thought to ask.

We may hear an account that unsettles our assumptions about service. Someone may prefer to talk about the music itself. If they do, we can follow their lead.

Veterans Day also gives the rest of us reason to examine our responsibilities. Freedom, equality, the rule of law, and human dignity depend on what people do in ordinary civic life. Honoring service includes caring for veterans and their families, and considering how faithfully we uphold the ideals we invoke at ceremonies.

This Veterans Day reminds us that we are seeking a more perfect union and that we are one people. With gratitude.

This November, I hope we make time for the familiar tributes and for a few personal songs. After the ceremony, someone beside us may have a story about a recording they’ve kept for fifty years, or a friend who always sang off-key.

The Top 5 Biotech Stocks I'd Buy Right Now Without Any Hesitation

📅 Nov 08, 2026  |  Category: Business  |  Read Source →

These are among the best the industry has to offer.

Biotech stocks have performed well in 2026, but things could change fairly rapidly. The industry is notoriously volatile, after all, and there are significant regulatory issues that may weigh on biotech companies. However, regardless of what happens over the next year or two, there are several biotechs with attractive prospects that are worth investing in for the long haul. Let's consider five of them.

Vertex Pharmaceuticals (VRTX +0.85%) has long been the leader in the cystic fibrosis (CF) medicines market, and the company's core therapeutic area remains a meaningful growth driver, with no major patent cliff expected over the next 10 years. However, the company is also making strides elsewhere. Consider Vertex's efforts in kidney diseases. It is inching closer to an approval for povetacicept, a medicine for IgA nephropathy.

Its Phase 3 pipeline also features inaxaplin, an investigational drug for APOL-1-mediated kidney disease. The biotech boasts several recent approvals whose sales should ramp up over the next few years, and it has also diversified its pipeline. Vertex's dominance in its core market and progress elsewhere make the stock a buy.

While Vertex's growth comes primarily from a single therapeutic area, Amgen (AMGN +0.03%) has taken a different approach. In the third quarter, the company had 17 products that delivered at least double-digit year-over-year sales growth. It also had 17 medicines with at least $1 billion annual revenue run rate. That's impressive, and it helps explain why Amgen has been able to overcome recent major patent cliffs without too much trouble, including the one for denosumab, a medicine for several bone-related conditions.

The drugmaker's deep pipeline, which features MariTide -- a highly promising weight-loss medicine -- should enable it to extend its approved lineup. Finally, Amgen is also an excellent dividend stock, having increased its payouts every year since initiating them in 2011.

Gilead Sciences' (GILD -0.41%) portfolio of medicines features some of the best-selling HIV drugs, such as Biktarvy and Descovy for PrEP. The company still generates the bulk of its sales from this area, and one recent approval has helped strengthen the company's position. Gilead Sciences earned approval for Bixlenvo, an HIV pill. However, Gilead Sciences has also made headway in other areas, particularly oncology, in recent years.

Gilead Sciences is betting big on its cancer drug pipeline, which is larger than its HIV pipeline. And as it launches new products in this area, the company will have a stronger, more diversified lineup. Meanwhile, revenue and earnings growth remain strong for the company, and the dividend is rock solid, too. Gilead Sciences has increased its payouts by 74.5% over the past decade.

Exelixis (EXEL +1.25%) isn't the most popular biotech company. It is much smaller than all of the others discussed here. However, Exelixis has managed to become successful in a corner of the vast and highly competitive oncology market. The company's most important medicine, Cabometyx, has earned multiple indications across multiple cancer types.

Cabometyx will likely face generic competition in the U.S. by early 2030, but Exelixis is ready for it. The company could earn approval for zanzalintinib, an investigational medicine for colorectal cancer, next year. It will target additional indications while also developing new cancer medicines. Exelixis' position in oncology makes it an attractive biotech to buy.

Regeneron Pharmaceuticals (REGN +0.16%) has encountered stiff competition for Eylea, a medicine that treats several eye-related diseases, in recent years. This has harmed the company's financial results. However, the drugmaker is slowly putting this issue in the rearview mirror. Revenue and earnings growth have rebounded, largely thanks to a new formulation of Eylea and Dupixent, a medicine for eczema. Regeneron's long-term plans feature both the new version of Eylea and Dupixent.

Dupixent may run into a patent cliff early next decade, but Regeneron will likely seek to protect its empire, notably by developing a high-dose formulation of Dupixent. The company also boasts an attractive pipeline of programs to diversify its lineup, including promising weight-loss candidates. Regeneron's comeback may just be getting started. It's still time to buy the stock.

Are You Waiting for Life to Begin?

📅 Nov 08, 2026  |  Category: World  |  Read Source →

After years or decades, problems and patterns can become deeply entrenched. Be a fly on the wall during a sample couples therapy session and witness the slow, deliberate work of changing those patterns for a more enduring love.

Posted November 8, 2026 | Reviewed by Lybi Ma

What if the person who brings you to life is also the one who brings you pain?

I was thinking about my own life and how, sometimes, it can feel as though it is divided into two halves: the life we live and the life we imagine sharing with a particular person.

When I tried to picture it, I saw a page divided by a crooked line (like the line in a broken-heart emoji). Another line runs alongside it, following its shape, inseparable from it. It was the connection, even when the two people were no longer together.

If you look at this picture, you might see different things. But I see three beings. Two who could not be more different, yet somehow belong to each other. And a third one: The space between them. The grey that separates their worlds, yet also connects them. That line is a boundary and a bridge.

Sometimes, light passes through that grey and reaches the other side, turning it bright for a moment. Life becomes colorful again. There is love, warmth, and a feeling that the world might be beautiful. But when the light fades, they return to their separate worlds, to the lives they have to live apart.

Maybe it is that space between the two moments, the third part of the picture, where you find yourself suspended in midair, unable to move forward or backward, not knowing where you stand.

One becomes the freedom. The other becomes the weight that gives that freedom meaning. But perhaps neither is as free as they seem. One does not know how to stop giving. The other does not know how to stop holding on. That is why some connections are so difficult to explain: they bring out parts of us we rarely see, beautiful, yet painful.

But what if the grey world in this picture is not only about the space between two people? What if it is also about the way we live?

Think about how much of our lives we spend waiting. Waiting for the right person, the right opportunity, the right moment. We look at our present lives and see only the grey. We imagine that once someone arrives, once we finally get what we have been longing for, we will begin to live.

But while we wait for that moment, what happens to the life we are already living?

We begin to believe that life is waiting for us somewhere in the future, beyond that line. This is why some connections are so powerful. For a moment, they remind us that we can feel something we thought we had lost. Something so human that, for a second, the rest of the world vanishes. We think we miss the person, but we miss the version of ourselves who felt that alive in their presence.

Have you ever considered that the person who awakened something inside you might not be the only place where that part of you can exist? What if the freedom, the love were yours all along, even before you met them? Maybe they helped you discover a part of yourself you never knew existed.

The connection was real. What you felt was real. It could have been painful, beautiful, and unlike anything you had experienced before. None of that becomes less meaningful just because the connection ended. But why do we have to hold on to the person to keep what they helped us discover?

Maybe it is possible to let someone go without having to erase what happened. Keep the part of yourself that came alive. You do not have to return to the connection to feel those things again. You can carry them into the rest of your life.

I know that looking inside yourself isn't comfortable. It means accepting some things, questioning others, and making sense of your own feelings. It also means recognizing that a new person is not responsible for the pain left by someone who came before them.

I would tell my younger self that it is okay not to have everything figured out. It is okay to take your time. And it is okay to miss someone without going back to them.

And if you are living in the grey right now, remember that the part of you that can see the light is still there. You may have stopped looking for it. Sometimes, all you need is to believe that the other side exists. But life on the grey side can be beautiful, too, if you allow yourself to see it. An ordinary morning can be warmth, joy in a small moment, and beauty in places you might have overlooked. And when you finally see it, let yourself feel it fully.

You might ask, what is the point of all this? Well, first of all, thank you for reading almost to the end. But if I had to leave you with just one thought, it's this: no matter where you are, whom you are with, or what circumstances you are living through, your life is still yours. You may not always have a choice about what happens, but you have some choice in how you meet it. You can spend your days holding on to what hurts, waiting for life to be different, or you can slowly begin noticing the beautiful things that are already here.

There is life everywhere, even in the dirt. And no, that doesn't mean we have to pretend everything is fine or feel grateful for every difficult thing that happens. It means that even in an imperfect life, there is still something worth noticing.

Your light is always there, with you. You do not have to spend your life waiting for someone else to turn it on.

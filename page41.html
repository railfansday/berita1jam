How to fix failing tests with an AI agent (without it deleting the tests)

📅 Nov 24, 2026  |  Category: Technology  |  Read Source →

Posted on Nov 24 • Originally published at openmel.dev

To fix failing tests with an AI agent, tell it which command must pass and what it may not touch, then let it run that command itself. In Mel – the agentic terminal (openmel.dev), put your test command in AGENTS.md or MEL.md, attach the failing output with Ctrl+↑ (⌃↑ on a Mac), and write a finish line such as "make pytest pass without skipping or deleting a test". Mel's agent reads the failing tests and the code, changes what it needs, and runs the tests again before it says it is done. You approve each edit and command that changes something, unless your settings allow it.

This guide covers the one rule that stops an agent from "fixing" tests the wrong way, how to set up your project once, the step-by-step in Mel, and how to handle a whole red test suite.

A failing test is one of the best tasks you can give an agent, because it comes with its own finish line. The agent does not have to guess what "done" means: the same command that failed must pass. It can run that command, read the exact error, change the code and run it again, as many times as it needs. A chat window cannot do that loop, because it cannot run anything; you would be copying errors back and forth by hand.

The fastest way to make a test pass is to change the test. An agent with no limits will sometimes do exactly that: loosen an assertion, skip the test, or delete it. Say what is off limits in every task:

That last line matters. Sometimes the test really is wrong, and you want to decide that, not the agent.

Mel's agent reads the rules files in your repository on every turn: AGENTS.md and CLAUDE.md, then MEL.md for rules meant only for Mel. If AGENTS.md names a test command, Mel uses it as the check to run before it says it is done.

Write it once and every task in that project follows it, for you and for your teammates.

A hundred failing tests usually have a few causes. Don't ask for all of them at once.

For a big suite, a lead agent can split the work. Type /orchestrate-cli or /orchestrate-agent and Mel's lead gives each worker its own files, then checks the combined result and runs the tests on disk.

Running one test first is faster and cheaper: the agent sees a short output instead of a whole suite, and each run is quick. Ask it to run the single failing test while it works, then the whole suite once at the end.

The answer streams to your terminal, and each command the agent runs or file it changes is printed on its own line. On macOS, set up the mel command once first: from v0.1.68, choose Install the mel command in the command palette. Approvals still apply; read the docs before you run it unattended.

Leave the model on auto and Mel picks one for each turn, or choose a mode: Cost-efficient for a simple assertion error, Genius for a hard bug that spans several files. If one model gets stuck, pick another from the model menu and send the same task; a fresh model often sees what the first one missed. On your own provider key, the turns cost 0 Mel credits.

Can an AI agent fix failing tests? Yes, when it can run them. Mel's agent runs your test command, reads the output, changes the code and runs the tests again until they pass or it reports what is left.

How do I stop the agent from deleting tests? Say so in the task and in AGENTS.md: "Fix the code, not the tests. Never skip or delete a test." Every edit also shows its diff on an approval card before it is written.

Where do I tell Mel my test command? In AGENTS.md, CLAUDE.md or MEL.md in your repository. If AGENTS.md names a test command, Mel uses it as the check.

What if the agent can't fix it? A task that stops making progress ends with a report of what was done and what is left. Narrow the task, add a fact, or try another model from the model menu.

Can I undo the agent's changes? Yes. In the code review panel, Undo takes back one change and ↩ Discard reverts one file.

Should I run one test or the whole suite? One test while the agent works, the whole suite once at the end. It is faster and costs less.

Can I fix tests from CI with Mel? Yes, with mel agent "..." in the project folder. Read the approvals section of the mel agent docs first.

Is it free? The terminal is free, and Mel's agent is free with your own API key. Paid plans start at $20 a month.

Download Mel from openmel.dev, add one line with your test command to AGENTS.md, run the tests, and hand the red block to the agent.

Fascia Release Is the Key to Regulating Your Nervous System, Getting Better Sleep, and Improving Skin

📅 Nov 24, 2026  |  Category: Health  |  Read Source →

Fascia, the thin web that envelops the face and body, is more powerful than you might think. Here’s how to release it

I’m curled up on a treatment bed in the Corinthia spa, feeling a knot of tension dissipate slowly from my neck and shoulders. Within minutes, tears prick my eyes. I’m familiar with the sudden catharsis bodywork can bring, but this is different. Known as “myofascial release”—a targeted therapy that works with fascia, the continuous matrix of connective tissue that wraps every muscle, nerve, and organ—it aims to reduce tightness and release restricted tissue, restoring its natural glide.

“Fascia is deeply connected to the entire sensory network,” explains Nadia Alibhai, a London-based osteopath who was unfazed by my heightened emotions. “When you move or hold stress, forces are transmitted through this interconnected system. It senses everything and dictates how the whole body responds. This treatment directly influences how we perceive and react to tension.”

Once dismissed as mere biological wrapping paper, fascia—made up of water, collagen, elastin, and hyaluronic acid—is now understood as a living, three-dimensional web. “It’s part of a complex system involving movement, circulation, lymphatics, posture, and tissue health,” Alibhai explains. When it works well, it keeps everything moving and prevents systems from becoming sluggish, but when it becomes restricted, often from scrolling, sedentary habits, or chronic stress, the fluid between the layers can thicken. This affects physical mobility and emotional well-being, leading to issues ranging from pain and stiffness to a dysregulated nervous system.

Fascia and neurology are intrinsically linked, explains skin-health expert Annee de Mamiel. “Fascia changes according to how we move, breathe, and repeatedly load the body,” she says. “Cortisol and adrenaline change our physiology; the nervous system alters breathing, muscular tone, and stress response. Over time, these repeated patterns affect the tissues.” It’s a catch-22: greater stress can tighten fascia, which in turn can send your body into fight-or-flight mode, prolonging the anxiety that caused the damage in the first place.

This mind-body connection is just one reason why fascia has piqued the wellness industry’s interest. Google searches for “fascia release” have soared in the past year, while facials targeting the system are becoming more popular. Robert Schleip, the director of the Fascia Research Group at Ulm University, attributes this to its holistic possibilities. “Fascia is now studied in relation to the autonomic nervous system, and therefore emotional regulation, as well as the immune system and aging,” he says. The latest findings show that supporting your fascia goes far beyond easing a tight neck; it's linked to reduced arterial stiffness and improved cardiovascular health.

The hit matches Bebe Rexha and Florida Georgia Line's "Meant to Be."

Ella Langley’s “Choosin’ Texas” logs a 50th week atop Billboard’s Hot Country Songs chart (dated Nov. 28), matching the all-time record set by Bebe Rexha and Florida Georgia Line’s “Meant to Be” in 2017-18.

“Choosin’ Texas” totaled 16.9 million official streams, 45.5 million in airplay audience and 6,000 sales in the United States Nov. 13-19, according to Luminate.

The song also extends its Billboard Hot 100 record to 29 weeks at No. 1.

Here’s a rundown of the five longest-leading Hot Country Songs hits (since the list became the genre’s singular songs chart in October 1958):

“Meant to Be” debuted atop Hot Country Songs in December 2017 and held the summit for 50 consecutive weeks. “Choosin’ Texas” reached No. 1 in its sixth week, in February, and led for 28 frames before Taylor Swift’s “I Knew It, I Knew You” interrupted its reign for two weeks in June. Langley reclaimed the summit on the July 4 chart and has remained there for 22 more weeks in a row.

The shared milestone also links two distinct moments in country’s crossover history. “Meant to Be” emerged during a sonically experimental boom, pairing pop star Rexha with FGL, a country cornerstone act in the 2010s, as genre-blurring hits helped define the era. The collaboration reached No. 2 on the Hot 100.

“Choosin’ Texas,” meanwhile, has contributed to country’s prominence this decade.

Streaming and radio airplay at country, pop and adult formats helped sustain both hits’ extraordinary longevity. “Meant to Be” spent 55 weeks atop Country Streaming Songs, with “Choosin’ Texas” up to 44. Their commands on Country Airplay were one and three weeks, respectively (reflecting radio’s more focused programming cycles).

Both songs also hit the top 10 on Pop Airplay, Adult Pop Airplay and Adult Contemporary, and sold strongly. “Meant to Be” reached No. 2 on Digital Song Sales over a yearlong stay on the chart; “Choosin’ Texas” has led for a record 22 weeks and counting.

Check Billboard.com next Monday, Nov. 30, to find out if “Choosin’ Texas” can pass “Meant to Be” and give Langley sole possession of the Hot Country Songs No. 1 longevity record.

Peralta, who will be going into his age-31 season in 2027, is coming off a campaign in which he didn't pitch up to his usual standards during a disastrous stint with the New York Mets. On the Rays' watch, Peralta made a series of adjustments that helped him find better results on the mound, including being named the ALCS MVP.

"It has been a roller coaster year for Peralta, who flopped with the Mets, rebounded with the Rays, then faced the Brewers (his former team) in the World Series and lost.
